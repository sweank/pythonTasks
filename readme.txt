Shikaku Solver

Назначение:
Программа решает 2D и 3D варианты головоломки Shikaku,
умеет генерировать новые задачи и запускать минимальный графический интерфейс.

Функциональность:
- решение 2D Shikaku;
- решение 3D Shikaku (разбиение на прямоугольные параллелепипеды);
- генерация 2D и 3D задач;
- запуск минимального Tkinter-интерфейса;
- обработка ошибок без сырого Traceback в обычном режиме.

Формат входных данных 2D:
Первая строка: <rows> <cols>
Далее rows строк по cols значений.
Пустая клетка: ., 0 или _

Формат входных данных 3D:
Первая строка: <depth> <rows> <cols>
Далее depth * rows строк данных.
Между слоями можно ставить строку ---
Пустая ячейка: ., 0 или _

Ключи запуска:
python -m shikaku puzzle.txt
python -m shikaku --mode 3d puzzle3d.txt
python -m shikaku --generate --rows 4 --cols 4
python -m shikaku --generate --mode 3d --depth 2 --rows 3 --cols 3
python -m shikaku --gui

Ограничения:
- 3D-версия сделана в минимальном варианте;
- генератор не гарантирует единственность решения;
- UI содержит только базовые элементы: режим, размеры, генерацию, решение и вывод результата.
